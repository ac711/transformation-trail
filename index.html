The Transformation Trail

A mission across the program
Briefing

Six teams. One outcome. Limited time.

A major tech program is approaching a critical delivery window. The teams know their systems. The owners know their decisions. But the signals across the program do not fully line up.

Your mission is not to take over. Your mission is to see the system, surface what matters, and unlock the passphrase.

Five challenges. One character each. One final code.

  • Read the signals across domains.
  • Find the constraint others haven't named yet.
  • Enable the right owner to make the right call.

Challenge 4 of 5 — Risk and control

The Only Irreversible One

A change advisory board reviews six changes for cutover weekend. Every one sounds risky. Only one has no real path back.

1. Drop a legacy column from the users table. A nightly snapshot exists and has been verified this morning. 2. Rotate the production database master key. Old key retained in the KMS for 30 days. 3. Migrate customer records to a new schema, then run a destructive DROP on the old schema in the same transaction. No pre-migration backup taken. 4. Reduce DNS TTL from 3600 seconds to 60 seconds. 5. Force-push a rewritten history to the main branch of the deployment repo. Every engineer has a local clone from this morning. 6. Toggle a feature flag on the new checkout flow at 5% traffic.
Identify the only genuinely irreversible change. Take its number.
Challenge 5 of 5 — Precision under pressure

The Two-Code Handshake

An integration test failed with an unexpected HTTP status code. The on-call left a cryptic note:

"Take the famous joke code — RFC 2324, the one about a teapot. Add the code returned when a resource has been permanently removed and clients should not come back to this URL. Sum them. Give me the last digit."
Find both HTTP status codes. Add them. Enter the last digit.
